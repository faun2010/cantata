# 翻译与搜索评审处理

- **默认启用 Ollama：保留。** 这是本机定制版的明确要求，默认地址和模型仍为 `127.0.0.1:11434`、`qwen3.8:27b`。连接拒绝或主机无法解析后增加端点级冷却，避免切换曲目时连续失败。
- **过期搜索排队：修复。** 输入本来已有防抖，并非每个按键都调用模型；现在还会按视图登记当前查询，取消不再被任何视图使用的运行中或排队中的扩展请求。新搜索优先入队，搜索请求默认最长 30 秒，普通长文翻译仍可使用 180 秒。
- **搜索结果重置与动画：修复。** 结果按文件去重后增量插入，保留持久索引与选中项。LLM 扩展终结、所有已提交 MPD 查询回复后才停止动画；清空查询立即停止，迟到回复不影响新查询。
- **简介链接：修复。** 翻译时用标记保留链接文字的位置，目标 URL 来自原文；模型不决定链接地址。缺失标记时在译文末尾保留原链接。原文显示入口继续可用。
- **SQLite FTS 括号：修复。** 每个别名组使用无括号的 FTS OR 表达式，各组通过独立 docid 子查询以 SQL AND 组合，不依赖 `SQLITE_ENABLE_FTS3_PARENTHESIS`。
- **艺人名变音：修复。** 精确匹配优先，随后允许 canonical 变音折叠，例如 `Motorhead` 与 `Motörhead`。多个不同 MusicBrainz ID 同样匹配时仍拒绝猜测。
- **代理与禁网：验证并明确初始化。** Qt 的默认网络管理器会使用应用级代理工厂；新增测试用本地 HTTP 代理验证了这一点。启动时明确初始化同一个代理工厂。`--no-network` 先前已禁止新翻译请求，缓存读取不受影响。
- **归一化开销：优化。** 查询别名在改变查询时归一化一次，每行候选字段只归一化一次。
- **缓存路径与 tooltip 模板：保持现状。** 现有缓存目录继续兼容，避免迁移导致重复翻译；tooltip 复用建议属于后续整理，不扩大此次行为修复。

验证包括翻译服务、中文搜索、FTS、艺人图片与简介链接回归测试，以及链接实际生产对象的 `tests/mpdsearchmodel_probe.cpp`。主程序已用私有 Qt SDK 构建；DMG 使用系统 `hdiutil` 打包，依赖和代码签名检查通过。

构建与手工清理命令见 [macOS 本机构建](macos-local-build.md)。清理工具默认只预览；本轮没有执行实际构建目录或 SDK 清理。
